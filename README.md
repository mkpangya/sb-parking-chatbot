> 정확한 내용은 주차사업팀에 확인해 주세요. (거주자 02-914-2008 / 공영 02-6925-0023, 평일 09:00~18:00)

## 폴더 구성
| 경로 | 내용 |
|---|---|
| `index.html` | 챗봇 화면 |
| `data/chatbot.db` | 챗봇이 읽는 공개용 SQLite 데이터 파일 |
| `vendor/` | 브라우저에서 SQLite를 읽기 위한 라이브러리(sql.js) |
| `tools/convert_db.py` | 엑셀 검사·변환 도구 |
| `tools/xlsx_to_sqlite.py` | 엑셀 → 공개용 DB 변환 도구 |

## 내용 수정 방법 (담당자)
1. 내부 보관용 엑셀(`parking_db.xlsx`)을 수정합니다. **엑셀은 이 저장소 안에 넣지 않습니다.**
2. 저장소 폴더에서 아래 명령을 실행합니다.
   `python tools\xlsx_to_sqlite.py ..\source\parking_db.xlsx data\chatbot.db`
3. "DB 생성 완료"가 나오면 GitHub Desktop에서 `data/chatbot.db`를 커밋하고 Push합니다.
4. 몇 분 뒤 사이트에 반영됩니다.

## 관리자 화면 (시험용) — `admin/index.html`
- 주소: `…/sb-parking-chatbot/admin/` (챗봇 화면에는 링크를 두지 않았습니다)
- 역할: **최고관리자** (전체 FAQ·센터·문의처·계정 관리), **사업장 관리자** (자기 센터 FAQ 편집, 공영주차센터는 할인·감면도 편집)
- 흐름: 사업장 관리자가 수정 → **작업용 DB 받기**(내부 보관) → 최고관리자가 **작업 DB 불러오기** → **공개용 DB 받기** → `data/chatbot.db` 교체 후 Commit·Push
- 공개용 DB에는 게시 N(비공개) 내용, 변경 이력(admin_log), 관리자 계정이 들어가지 않습니다.
- ⚠️ 계정 선택만으로 들어가는 **시험용**입니다. 실제 운영 전 서버 로그인 또는 GitHub 저장소 권한으로 바꿔야 합니다.
- ⚠️ `admin_accounts_INTERNAL.json`, `chatbot_work.db`는 저장소에 올리지 마세요. (`.gitignore`에 `internal*.db`를 두고, 계정 파일은 이름에 INTERNAL을 붙였습니다.)

### 관리자 계정·비밀번호
- 최초 비밀번호는 `sb111111`이며, 처음 로그인하면 새 비밀번호를 정해야 합니다.
- 작성 규칙: 영문 대문자·소문자·숫자·특수문자 중 2종류 이상이면 10자리 이상, 3종류 이상이면 8자리 이상 (개인정보의 안전성 확보조치 기준 제6조 해설서 기준, 최신 개정 여부 확인 필요). 아이디 포함·연속문자·같은 문자 3번 연속 금지.
- 5회 틀리면 잠금 (최고관리자가 해제).
- 비밀번호는 PBKDF2-SHA256 해시로만 저장합니다. 계정 파일(`admin_accounts_INTERNAL.json`)은 내부 보관하세요.
