저장은 작업 DB에 반영됩니다. 챗봇 공개는 '내보내기·이력' 탭에서 공개용 DB를 받아 저장소에 올려야 완료됩니다.

할인·감면 유형

담당: 공영주차센터 (최고관리자 포함). 표를 고친 뒤 '저장'을 누르면 표 전체가 새로 기록됩니다.

사업장(센터) 정보

최고관리자만 수정합니다. 챗봇 하단 문의전화에 표시됩니다. 연락처가 없으면 저장되지 않습니다. (공통은 비워 둠)

문의처

최고관리자만 수정합니다.

사업장 관리자 · 권한 관리

계정 정보는 사람의 이름·연락처를 포함할 수 있는 개인정보입니다. 이 화면에서 내려받는 계정 파일은 저장소에 올리지 말고 내부 보관하세요. 지금 목록은 예시입니다.
권한 규칙: 최고관리자는 전체 FAQ·센터·문의처·계정을 관리합니다. 사업장 관리자는 자기 센터 FAQ와(공영주차센터인 경우) 할인·감면만 편집합니다.
표시 이름(직책)역할담당 센터사용

작업 흐름

  1. 사업장 관리자가 FAQ·할인 정보를 수정하고 '작업용 DB 받기'로 저장합니다. (내부 보관)
  2. 최고관리자가 해당 파일을 '작업 DB 불러오기'로 열어 내용을 검토합니다.
  3. 최고관리자가 '공개용 DB 받기'를 누르면 게시(Y) 내용만 들어간 chatbot.db가 내려받아집니다.
  4. 받은 chatbot.db를 저장소의 data 폴더에 덮어쓰고 GitHub Desktop에서 Commit → Push 합니다. 1~2분 뒤 챗봇에 반영됩니다.
